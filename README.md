# Breast Cancer Data Analysis Using Tableau

## Project Overview

The Breast Cancer Data Analysis project aims to analyse and visualize breast cancer diagnostic data using Tableau. The project uses the Breast Cancer Wisconsin (Diagnostic) dataset to identify patterns and differences between benign and malignant tumours.

The dataset contains various features related to tumour characteristics, such as radius, texture, perimeter, area, smoothness, and compactness. Using Tableau, these features are explored through interactive charts and visualizations to make the data easier to understand and interpret.

The main focus of this project is to compare benign and malignant diagnoses, analyse tumour measurements, and present meaningful insights through an interactive dashboard.

## Objectives

- Analyse the distribution of benign and malignant breast cancer cases.
- Compare tumour characteristics between benign and malignant diagnoses.
- Visualize average tumour radius and area based on diagnosis.
- Identify patterns and differences in the dataset using charts.
- Create an interactive Tableau dashboard for better data understanding.

## Tools and Technologies Used

- Tableau – Data visualization and dashboard creation.
- Microsoft Excel / CSV – Dataset handling and preprocessing.
- GitHub – Project documentation and version control.

## Dataset Description

The project uses the Breast Cancer Wisconsin (Diagnostic) dataset, which contains 569 records and 30 numerical features describing tumour characteristics.

The target variable represents two diagnosis categories:
- Benign (B) – Non-cancerous tumour.
- Malignant (M) – Cancerous tumour.

## Visualizations Created

1. **Breast Cancer Diagnosis Distribution:** Displays the distribution of benign and malignant cases.
2. **Average Radius by Diagnosis:** Compares the average tumour radius for both diagnosis categories.
3. **Average Tumour Area by Diagnosis:** Shows the differences in average tumour area between benign and malignant cases.
4. **Interactive Dashboard:** Combines the visualizations into a single dashboard for easy comparison and analysis.

## Expected Outcome

The project provides a clear visual understanding of breast cancer diagnostic data. It helps identify differences in tumour measurements between benign and malignant cases and demonstrates how Tableau can be used to explore healthcare datasets effectively.

## Conclusion

This project demonstrates the use of Tableau for healthcare data analysis and visualization. By analysing tumour characteristics and comparing diagnosis categories, the dashboard presents meaningful insights in an understandable visual format. It is an educational data analysis project and is not intended for medical diagnosis or clinical decision-making.
